# Coptic Calendar

Coptic chronology, formatting and ICU adaptation remain local. Generic arithmetic, civil/JDN helper operations, provider ABI and validation are supplied by the true Common 1.19.81 library (a99ef676b0e43c7e645c81756e3fd38be0a54406). This provider builds the exact Common submodule archive, eliminating local Common source/header copies. Its native installer and independent accuracy checks remain mandatory.
