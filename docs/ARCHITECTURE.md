# Coptic Calendar

Coptic chronology, formatting and ICU adaptation remain local. Generic arithmetic, civil/JDN helper operations, provider ABI and validation are supplied by the true Common 1.19.80 library (dc4aac326964ca4400b6e21851d16eea674040c8). This provider builds the exact Common submodule archive, eliminating local Common source/header copies. Its native installer and independent accuracy checks remain mandatory.
